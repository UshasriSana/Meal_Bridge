# MealBridge 🍽️
Collecting leftovers, connecting lives.

## Features
- Donor food listing
- Receiver food acceptance
- Expiry-based auto removal
- Real-time updates

## Tech Stack
- HTML, CSS, JavaScript
- Python (Flask)
- SQLite

## How to Run
1. pip install flask
2. python app.py
3. Open http://127.0.0.1:5000
